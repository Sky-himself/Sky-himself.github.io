schedule:
  - week: 1
    date: Homework 1
    topic: Number systems and Boolean algebra
    description: >
      Conversion among decimal, binary, octal, and hexadecimal, including a fractional value. Truth tables for two three-variable expressions, a Boolean identity proved from a truth table, algebraic proofs with the law named at each step, dual and complement, gate-level simplification, and the output waveform of a small function with gate delay ignored.
  - week: 3
    date: Homework 3
    topic: Karnaugh maps
    description: >
      Sum-of-products simplification, rewriting functions as products of maxterms, checking identities on a map, don't-care entries, a product-of-sums and a NOR-only implementation, recovery of a sum of products from a NAND-only circuit, and whether a simplified function can be drawn in NAND only.
  - week: 5
    date: Homework 5
    topic: Binary arithmetic and data-path blocks
    description: >
      The same bit strings read as unsigned, sign-magnitude, ones' complement, and twos' complement. Four-bit twos'-complement addition and subtraction, with the overflow flag. Gray code converted to decimal. A full adder built from a decoder and NOR gates, and a full adder built from two multiplexers controlled by the carry-in.
  - week: 7
    date: Homework 7
    topic: Synchronous state machines
    description: >
      An output waveform for a clocked machine that starts in a named state. Conversion of a Mealy diagram to Moore. A sequence detector, Mealy or Moore, with a behavioral Verilog description. A synchronous counter on T flip-flops with the cycle 0, 1, 3, 4, 5, 7. A two-input machine specified in both Mealy and Moore form: it waits for two identical input pairs, then raises the output when the first input held an odd number of ones.
