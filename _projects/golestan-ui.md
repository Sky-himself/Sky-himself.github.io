Course project in human-computer interaction at IK International University, spring 2019. I listed the tasks in the Golestan student system, grouped related ones, and redesigned the desktop interface so a student could move between linked tasks without hunting through the old navigation. Responsive layout was outside the project scope, so the layout is for a desktop width.
